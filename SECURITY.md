# Security Policy

## Supported Versions

Coinwatch does not currently publish versioned releases. Security fixes are applied to the latest commit on `main`.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Older commits and archived branches | No |

## Reporting a Vulnerability

Do not disclose security-sensitive findings in a regular GitHub issue.

Repository collaborators should open a private repository security advisory from **Security → Advisories → New draft security advisory**. If that interface is unavailable, contact the repository owner directly and include:

- the affected component and version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any known mitigation.

Please allow time to reproduce and assess the report before broader disclosure. Confirmed vulnerabilities will be remediated on `main` and disclosed after a fix is available.
